# Spec: `src/utils/i18n.js`

## Purpose
Internationalization system with embedded translations for Spanish and English. Provides translation functions, language switching, and DOM updates.

## Dependencies

### state
| Property | Access (R/W) | Context |
|-----------|-------------|----------|
| `localStorage` | read/write | store `weatherhist_language` |

### DOM
| Element | Access type | Context |
|----------|---------------|----------|
| `[data-i18n]` | querySelectorAll / textContent | applyTranslations |
| `[data-i18n-placeholder]` | querySelectorAll / setAttribute | applyTranslations |
| `[data-i18n-title]` | querySelectorAll / setAttribute | applyTranslations |

## Public API

### `export const translations: Object`

**Description:** Object with translations for `es` and `en`, organized by sections: config, theme, overlay, search, map, nav, topPanel, pollen, minimap, weatherCodes, weather, aqiLevel, aqi, pollenLevels, days, months. The `config` section includes keys for YIP personal notes: `yipNotesLabel`, `yipNotesPlaceholder`, `yipNotesSave`, `yipNotesSaved`, `yipNotesDelete`. Also includes keys for YIP moods: `yipMoodsLabel`, `yipMoodsSave`, `yipMoodsSaved`, `yipMoodsParam`. Also includes keys for YIP health conditions: `yipCategoryHealth`, `yipCold`, `yipAllergies`, `yipConditionsLabel`, `yipConditionsSaved`. The `moods` section contains labels for each mood: `moods.happy`, `moods.neutral`, `moods.sad`, `moods.angry`, `moods.anxious`, `moods.tired`.

### `export function setLanguage(lang: string): void`

**Description:** Changes active language if exists in `translations`, persists in localStorage and applies translations to DOM.

**Parameters:** `lang: string` — `'es'` or `'en'`

**Mutates state:** localStorage

### `export function getLanguage(): string`

**Description:** Returns the current active language.

**Return:** `'es'` | `'en'`

### `export function t(key: string, fallback?: string): string`

**Description:** Translates a nested key (e.g. `"config.language"`). Returns the translated value, the fallback if provided, or the key itself if nothing is found.

### `export function getLocale(): string`

**Description:** Returns the locale for date formatting according to active language.

**Return:** `'es-ES'` | `'en-US'`

### `export function applyTranslations(): void`

**Description:** Iterates the DOM and updates `textContent`, `placeholder`, and `title` of elements with `data-i18n`, `data-i18n-placeholder`, `data-i18n-title` attributes.

## Behavior

1. `currentLanguage` is initialized from localStorage or default `'es'`
2. `setLanguage` only changes if `translations[lang]` exists
3. `t(key)` traverses keys separated by `.` for nested access
4. weatherCodes use `t('weatherCodes.' + code)` with fallback to `weatherCodes.unknown`

## Edge Cases

| Input | Expected behavior |
|---------|------------------------|
| `t('non.existent.key')` | Returns `'non.existent.key'` |
| `t('non.existent.key', 'fallback')` | Returns `'fallback'` |
| `setLanguage('fr')` | Does not change (not in translations) |
| Uncovered WMO code | `t('weatherCodes.' + code)` returns `'weatherCodes.unknown'` → fallback to `t('weatherCodes.unknown')` |

## Test Scenarios

1. **Direct translation:** `t('config.language')` returns expected string per language
2. **Nested key:** `t('days.short.0')` returns first day
3. **Fallback:** non-existent key with fallback returns the fallback
4. **No fallback:** non-existent key without fallback returns the key itself
5. **getLanguage:** returns current language
6. **setLanguage:** changes language and persists in localStorage
7. **getLocale:** `es` → `'es-ES'`, `en` → `'en-US'`
8. **applyTranslations:** updates DOM elements with data-i18n
9. **YIP notes key (ES):** `t('config.yipNotesLabel')` returns "Notas personales"
10. **YIP notes key (EN):** `t('config.yipNotesLabel')` returns "Personal notes" after `setLanguage('en')`
11. **YIP notes save:** `t('config.yipNotesSave')` returns "Guardar nota"
12. **Mood label (ES):** `t('moods.happy')` returns "Feliz"
13. **Mood label (EN):** `t('moods.happy')` returns "Happy" after `setLanguage('en')`
14. **Mood UI label:** `t('config.yipMoodsLabel')` returns "Estado de ánimo" (ES) / "Mood" (EN)
15. **Mood save:** `t('config.yipMoodsSave')` returns "Guardar estado" (ES) / "Save mood" (EN)
16. **Health category (ES):** `t('config.yipCategoryHealth')` returns "Salud"
17. **Health category (EN):** `t('config.yipCategoryHealth')` returns "Health" after `setLanguage('en')`
18. **Cold condition (ES):** `t('config.yipCold')` returns "Resfriado"
19. **Cold condition (EN):** `t('config.yipCold')` returns "Cold" after `setLanguage('en')`
20. **Allergies condition (ES):** `t('config.yipAllergies')` returns "Alergias"
21. **Allergies condition (EN):** `t('config.yipAllergies')` returns "Allergies" after `setLanguage('en')`
22. **Conditions label (ES):** `t('config.yipConditionsLabel')` returns "Condiciones"
23. **Conditions saved (ES):** `t('config.yipConditionsSaved')` returns "Condiciones guardadas"
